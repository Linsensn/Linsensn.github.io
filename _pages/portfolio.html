演示：移动端浏览器扫码直接使用WebAR，完成书脊识别、检索、实景导航，无需安装App

项目背景：解决高校图书馆“知道书名，找不到实体书籍”痛点；系统部署于腾讯云2C4G无GPU轻量服务器，硬件资源极度受限。作为项目算法与技术总负责人，在10人整体项目（开发部4人，开发+质控合计6人）中，主导完成整套WebAR智能图书导引系统，Android浏览器直接访问即可实现书脊目标检测、OCR文本识别、三级检索、AR实景导航全链路闭环。

我的职责：负责计算机视觉算法方案设计、FastAPI后端整体架构设计；制定数据库、接口、代码注释规范；主导Issue‑PR驱动开发流程，负责代码评审与版本合并，完成容器化生产环境交付。

1. 计算机视觉算法实现

  • 自建图书馆实景数据集，完成书脊目标检测、OCR识别数据采集、标注与清洗；针对密集书架、大透视畸变、逆光阴影做场景覆盖；严格执行标注质量管控策略。
  • 基于YOLOv8‑Nano完成迁移训练；通过ONNX做常量折叠、Conv‑BN算子融合模型轻量化；设计IoM嵌套过滤、透视坐标逆映射、多尺度预处理解决密集场景误检。
  • 构建SQL精确匹配 → Levenshtein加权模糊纠错 → LLM混元1.8B语义确认三级检索状态机，处理OCR识别错字、形近字干扰。

YOLOv8‑Nano训练损失、mAP精度收敛曲线，验证模型泛化能力

  • 设计完整业务异常体系：区分HTTP标准异常与1xxxx/3xxxx业务状态码，全局异常拦截；实现并发信号量限流，控制图像推理并发数，保护2C4G服务器。

基于大语言模型的高并发推理与微调系统

算法与技术总负责人 2026.06 - 2026.08

项目背景：针对电商评论分析场景，解决大模型处理欲扬先抑、欲抑先扬等复杂情感文本时易被关键词误导产生极性识别反转，以及多模型交叉验证时显存溢出、I/O 阻塞问题；基于 Llama3-8B 与 4.5 万条全量数据集构建高并发评测系统。

我的职责：负责微调 / 量化方案、推理优化与并发评测工具的设计与实现。

  • 模型微调与评测：搭建自动化实验流水线，完成多量级数据集消融实验与多架构横向对比；通过混淆矩阵分析 4bit 量化、DoRA 机制带来的模型行为变化。
  • 推理优化：底层实现 “单基座常驻 + 多 Adapter 毫秒级热插拔”，规避多模型切换时权重重复加载；设计强校验异常拦截、逆向惩罚状态机抑制模型输出发散。
  • 量化成果：全量模型准确率 91.54%、F1 = 0.9129；大幅降低多模型切换显存开销，交付可交互的大模型批量评测能力。

技术栈：PyTorch、Llama-3-8B、4bit 量化、DoRA、LoRA、QLoRA、Adapter 热插拔、大模型并发评测 · GitHub 源码

对岗位的匹配点：LLM 微调 / 量化 / 推理优化 + 并发工程能力，贴近大模型推理与训练优化方向。
