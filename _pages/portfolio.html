① WebAR 轻量化实景追踪系统 ｜ 算法与技术总负责人 2025.09 - 2026.01

项目背景：面向高校图书馆密集书架排布的实景图书检索业务，在云端 2C4G 无 GPU 的极小算力约束与大透视畸变场景下，作为 7 人团队技术负责人，交付整套 WebAR 智能导引系统，实现浏览器端无需 APP 即可完成书脊检测、文本识别、检索导航。

我的职责：负责整体算法方案设计与后端工程架构，统筹团队协作与代码质量门禁。

  • 算法与轻量化：采集标注自建书脊 YOLO、OCR 数据集，完成 YOLOv8-Nano 训练；使用 ONNX 常量折叠、ConvBN 算子融合做模型收缩，实现 纯 CPU 毫秒级推理（mAP50 = 0.978）。
  • 检索与识别：设计 IoM 嵌套过滤解决密集场景误检，透视坐标逆映射 + 多尺度预处理完成文本 ROI 提取；构建“精确匹配 → 编辑距离纠偏 → LLM 语义纠错”三级检索状态机。
  • 后端与工程化：搭建 FastAPI 分层后端，SQLAlchemy + Alembic 落实 Code-First 数据库；Redis 轨迹缓存屏障（LRU/TTL）；SSE 流式响应、Pydantic 契约校验、异常拦截；Docker 容器化部署，健康探针 + 模型预加载规避 OOM。
  • 团队管理：制定 Issue 驱动开发、Git 分支、PR 评审质控门禁，统一团队数据库迁移、接口定义、代码注释全套规范。
  • 量化成果：依靠缓存、异步限流策略保障高并发图像请求下系统 零宕机；完成端到端业务闭环，容器化可直接部署上线，配套完整工程开发文档。

技术栈：YOLOv8-Nano、ONNX、PaddleOCR、FastAPI、SQLAlchemy、Alembic、Redis、Docker、JWT · GitHub 源码 · Gitee 源码

对岗位的匹配点：端侧 / 云端低算力模型优化能力 + 高并发后端稳定性 + 完整工程化交付，贴近推理服务与业务后端场景。

项目背景：针对电商评论分析场景，解决大模型处理欲扬先抑、欲抑先扬等复杂情感文本时易被关键词误导产生极性识别反转，以及多模型交叉验证时显存溢出、I/O 阻塞问题；基于 Llama3-8B 与 4.5 万条全量数据集构建高并发评测系统。

我的职责：负责微调 / 量化方案、推理优化与并发评测工具的设计与实现。

  • 模型微调与评测：搭建自动化实验流水线，完成多量级数据集消融实验与多架构横向对比；通过混淆矩阵分析 4bit 量化、DoRA 机制带来的模型行为变化。
  • 推理优化：底层实现 “单基座常驻 + 多 Adapter 毫秒级热插拔”，规避多模型切换时权重重复加载；设计强校验异常拦截、逆向惩罚状态机抑制模型输出发散。

技术栈：PyTorch、Llama-3-8B、4bit 量化、DoRA、LoRA、QLoRA、Adapter 热插拔、大模型并发评测 · GitHub 源码

对岗位的匹配点：LLM 微调 / 量化 / 推理优化 + 并发工程能力，贴近大模型推理与训练优化方向。
